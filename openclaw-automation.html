OpenClaw Automation

Last updated: September 24, 2026

OpenClaw Automation is a personal automation project run by Nam (Nguyễn Thanh Nam), built on the open-source OpenClaw agent framework, self-hosted on a private server that Nam owns and administers. It is not a public product or service — it exists solely to automate tasks for Nam's own accounts.

One of its agents, mail_reader, uses Google OAuth to read Gmail on behalf of Nam's own Google accounts, so the automation can summarize and act on incoming email. No other Google account can be connected — access is restricted to accounts explicitly added by Nam as test/authorized users.

Privacy Policy

This Privacy Policy explains how OpenClaw Automation handles data accessed through Google APIs.

1. Data Accessed

The mail_reader agent accesses Gmail data (message content and metadata) via the Gmail API, using OAuth 2.0, for Nam's own connected Google account(s) only.

2. How the Data Is Used

Email data is read to let the automation summarize messages and trigger personal workflows (e.g. notifications). Data is processed on Nam's own private server and is not sold, rented, or shared with any third party, and is not used for advertising.

3. Data Storage and Retention

Any data cached to support the automation is stored on Nam's own private server, protected behind authentication, and retained only as long as needed to operate the automation. Deleting the connected account or revoking access (see Section 5) stops further access immediately.

4. Third-Party Sharing

No data obtained through Google APIs is shared with third parties. Where the automation uses a third-party AI provider (e.g. to summarize text), only the minimum text needed for that specific task is sent to the provider under Nam's own account with that provider, subject to that provider's own privacy policy.

5. Revoking Access

Access can be revoked at any time via Google Account → Security → Third-party access.

6. Google API Services User Data Policy

OpenClaw Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
